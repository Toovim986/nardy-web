# Нарды — веб-сборка (прототип)

Ранняя однопоточная веб-сборка мобильной игры «Нарды» (длинные и короткие) на Godot 4.7.2
(Compatibility / WebGL 2). Открыть: страница GitHub Pages этого репозитория. Версия сборки — `version.json`.

Прототип для просмотра: первый запуск занимает несколько секунд, первые открытия экранов и первые
анимации медленнее из-за компиляции шейдеров. Игровая валюта внутренняя, платежей нет.
Репозиторий содержит только собранные файлы игры.
